# NesiaTech/.github

Organization profile for [Nesia Tech](https://github.com/NesiaTech).

- `profile/README.md`: the profile shown on the organization page.
- `profile/assets/`: the banner in its dark and light variants. The profile picks one with `prefers-color-scheme`.
- `banner/banner.html`: source of the banner, built on the live design system from [nesia.tech](https://nesia.tech).
- `banner/render.sh`: regenerates both PNGs from the source. Run it after changing the banner or the brand.
