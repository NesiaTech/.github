### Open source

[**cosmoSys**](https://github.com/cosmoBots/cosmoSys) is open-source software (GPLv3) by [cosmoBots.eu](https://cosmobots.eu) that takes Redmine further: projects that read like books, stable identifiers, live diagrams and reports. [**cosmoSys-Req**](https://github.com/cosmoBots/cosmoSys_Req) adds requirements management on top. We set them up for your project and, if you need it, host them in the EU or install them on your machines.

- [`cosmosys_adr`](https://github.com/NesiaTech/cosmosys_adr): Architecture Decision Records for cosmoSys.
